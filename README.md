# 音量阶数（VolumeControl）

> 一句话：**把手机音量调得更"准"、更"好用"**——尤其是蓝牙耳机音量偏大、低档位没声音、相邻两档听感几乎一样时，用它来精细掌控每一格音量。

这是一个需要 **Root + LSPosed** 的 Android 系统增强工具（模块 + 配套设置 App）。它不改变你平时的使用习惯，只是在系统底层把"音量刻度"重新划分，让音量条更细、更好调。

## 这个 App 能帮你解决什么

它给你对手机**媒体音量**的三个可精细控制的量：

- **最小音量**：抬高音量条的第 1 档起点——低档听不见、或一开就没声时，把最小值调高（如 8~20），让最低档也能听清。
- **最大音量**：限制音量条的最高点——觉得默认最大音太响、想保护听力或在安静环境使用时，把最大值调低。
- **音量滑块精度**：整条音量条被切成多少格（档位数量，可设 **10~127**）——格数越多，每一格之间的音量差越小、调得越细，解决"相邻两档听感相同""一开就炸、再小就没声"。

配合以下能力，把外放、有线耳机、蓝牙耳机都调到合适的手感：

- **音量键步进**：自定义按一次音量键跳多少，把整条音量条均分成你设定的段数，按键落点稳定、可预期。
- **两种蓝牙耳机控制模式**：绝对音量映射 / 手机端软件衰减，针对耳机内部档位少、低音量重复等问题从根本解决。
- **真实曲线查看器**：内置读取本机 ROM 的音频配置，按设备类别（外放/有线/蓝牙）展示每一档对应的增益，纵轴可切"感知响度 / dB 线性"。

> 说明：本 App 只影响**媒体音量**（音乐、视频、游戏等），来电、通知、闹钟等其他音量不受影响。

## 测试与运行环境

- **开发与测试机型**：Redmi 12 5G（型号 `23077RABDC`，代号 `sky`）
- **系统**：小米 **HyperOS 2**（版本号 `OS2.0.205.0.VMWCNXM`），基于 **Android 15**（API level 35，安全补丁 2025-08）
- **本机原生媒体档位**：15 档
- **系统版本支持**：Android 8.0 及以上（minSdk 26）
- **必备前提**：设备已 **Root**（授予 su 权限）+ 已安装并启用 **LSPosed**（libxposed API 102+）

> 因为要修改系统音量行为，必须 Root 并通过 LSPosed 生效；未 Root 的设备无法使用。上述机型/系统为本项目实测基准，其他机型/ROM 的曲线与档位数会因厂商配置不同而不同（App 会自动读取本机实际配置）。

## 快速上手

1. 安装本 App，并在 LSPosed 中启用「音量阶数」模块（作用域已静态声明，无需手动勾选目标应用）。
2. 打开 App，在「媒体音量档位」卡片里打开 **「启用档位修改」** 开关。
3. 按需调整：档位数量、音量键步进、音量范围（最小/最大/曲线）、生效模式（绝对音量 / 相对音量 / 默认）。右侧曲线图与下方映射表会**实时预览**效果。
4. 点 **「保存修改」**，按提示重启对应组件使其生效：
   - 修改了**档位数** → 需要「重启系统框架」（屏幕短暂黑屏后自动恢复）；
   - 只改了**音量范围/模式** → 通常「重启蓝牙」即可。
5. 想回到手机原生行为：选 **「默认」** 模式，或点 **「恢复系统默认」**。

## 核心概念（通俗版）

- **档位数量（媒体音量档位）**：音量条被切成多少格。系统通常 15 或 30 档；这里可设 **10~127**，越多越细腻。
- **音量键步进**：把整条音量条均分成 **10~29** 段，每按一次音量键恰好跳一格；拖动滑条仍可逐格精调。
- **三种生效模式**（对蓝牙/有线/外放统一生效）：
  - **绝对音量**：手机档位映射为 0~127 的蓝牙绝对音量发给耳机，低音量区间距更大，避免"首档太响/两档无异"。
  - **相对音量**：停用耳机绝对音量，由手机端直接衰减信号，耳机固定自身音量，从根本上消除档位重复。
  - **默认**：不改档位数、不重映射，走系统原生行为（只读展示系统真实音量曲线）。
- **音量范围**：「最小」抬高第 1 档（低档听不见时上调），「最大」限制最高音量。
- **真实曲线查看器**（「默认」标签下）：读取本机 ROM 音频配置（音量引擎表 / 策略表 / AOSP 参考三级回退），按 **外放 / 有线耳机 / 蓝牙** 分标签展示；纵轴可切换 **感知响度** 或 **dB 线性**，映射表同步显示每档的相对增益百分比或硬件 dB 值。

## 两种模式对比

| | 绝对音量（默认推荐） | 相对音量 |
|---|---|---|
| 原理 | 保持绝对音量，曲线映射 AVRCP | 停用绝对音量，手机端软件衰减 |
| 适用场景 | 耳机支持绝对音量、想让低音量更细腻 | 耳机内部档位少（如 8~19 档）、低音量问题严重 |
| 耳机按键 | 可控制手机音量并同步显示 | 只控制耳机自身音量，不同步显示 |
| 低音量表现 | 增强曲线拉开每档间距 | 完全由手机曲线决定，无耳机量化干扰 |

## 常见问题

- **改完没生效？** 档位数变化必须「重启系统框架」；只调范围/模式一般「重启蓝牙」即可。App 会在保存后提示需要重启什么。
- **会不会变砖/影响其他音频？** 只作用于媒体音量；随时可用「恢复系统默认」还原。
- **一定要 Root 吗？** 是的，本工具通过 LSPosed 修改系统音量行为，需要 Root。

### 项目结构

```
app/src/main/java/com/xiefeihong/volumecontrol/
├── MainActivity.java              # 主界面：参数设置、状态检测、实时预览、真实曲线查看器接线
├── CurveChartView.java            # 自定义 View：绘制档位映射曲线图 / 系统真实默认曲线
├── NativeVolumeCurve.java         # 读取并解析 ROM 真实音量曲线（引擎表/策略表/AOSP 回退、dB 归一）
├── Prefs.java                     # 配置常量、档位/键步网格吸附算法（App 与 Hook 端共用）
├── Range.java                     # 单模式音量范围值对象（min/max/curve）
├── VolumeConfig.java              # 不可变配置值对象 + 10 字段序列化/解析
├── VolumeMode.java                # 生效模式「枚举即策略」抽象（绝对/相对）
├── Avrcp.java                     # AVRCP 绝对音量映射计算与预览/映射表文本生成
├── XposedEntry.java               # LSPosed 模块入口（libxposed API 102）
├── XposedKit.java                 # 共享基础层：日志、反射工具、配置读取、Context 解析
├── SettingsGlobal.java            # Settings.Global 薄封装（配置读取通道）
├── AudioHooks.java                # 系统框架侧 Hook：档位保险 + 键步接管 + 软件衰减 + 网格吸附
├── BtHooks.java                   # 蓝牙进程侧 Hook：绝对音量曲线替换 + 设备上报拦截
├── ShellResult.java               # root shell 执行结果值对象（退出码 + 输出）
└── Shell.java                     # root shell 工具：配置写入、蓝牙/系统重启、日志读取
```

```bash
./gradlew assembleDebug
```

### 配置格式

配置以统一的 **10 字段** 格式写入 `Settings.Global`（键名 `volume_steps_hook_config`），并镜像备份到 `/data/system/volumecontrol_config`，供 Hook 端在 SettingsProvider 未就绪时读取。字段按「全局项 → 各模式 `min;max;curve`」连续排列：

```
启用;媒体档位;键步段数;模式;A.min;A.max;A.curve;B.min;B.max;B.curve
```

其中 `模式` 取 `0=默认（系统直通）` / `1=绝对音量` / `2=相对音量`；不兼容任何历史格式。
