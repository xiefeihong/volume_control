模块由两部分组成：
- Android 应用（`app/src/main/java/com/xiefeihong/volumecontrol/MainActivity.java`）：基于 ViewBinding + Material 的主题 UI，负责采集各音频流的原始档位基准、计算缩放后的目标档位数、预览蓝牙 AVRCP 绝对音量映射、通过 `Shell.su()` 以 root 身份写入 `Settings.Global` 并触发 `system_server` 软重启。
- LSPosed 模块入口（`XposedEntry.java` + `assets/xposed_init`）：实现 `IXposedHookLoadPackage`，在加载包名为 `android` 的系统框架时 hook `AudioService.createStreamStates()`，按比例缩放静态字段 `MAX_STREAM_VOLUME[]`；配置优先从 `Settings.Global`（`Prefs.GLOBAL_KEY`）读取，回退到 `XSharedPreferences`。

共享层 `Prefs.java` 是 App 进程与 Hook 端共用的纯常量/编解码类，刻意不引用任何 Xposed API，以保证两类构建产物可复用同一份配置协议（`encodeConfig`/`decodeConfig` 使用分号分隔字符串）。`Avrcp.java` 独立实现 AOSP `AvrcpVolumeManager` 的 `absVolume = round(step * 127 / max)` 换算逻辑，供界面预览。`Shell.java` 封装所有 su 命令执行、root/LSPosed/Magisk 检测及 `settings put/get global` 操作。

依赖方向：`MainActivity` → `Prefs` + `Avrcp` + `Shell`；`XposedEntry` → `Prefs` + `XSharedPreferences` + `XposedBridge`；两者互不直接依赖，仅通过 `Prefs` 定义的键与序列化格式通信。Gradle 侧通过 `compileOnly de.robv.android.xposed:api:82` 让 Xposed API 仅在编译期存在，运行期由 LSPosed 提供。
