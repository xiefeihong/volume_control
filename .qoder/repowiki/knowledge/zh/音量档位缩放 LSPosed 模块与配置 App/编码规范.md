- 对外暴露的配置键、常量值（如 `KEY_ENABLED`、`PERCENT_MIN/MAX/STEP`、`STREAM_MUSIC_INDEX`、`AVRCP_MAX_VOLUME`）统一集中在 `Prefs.java` 中作为 `public static final` 常量，避免魔法数字散落各处。
- 跨进程（App 进程 ↔ system_server Hook 端）共享配置采用 `Prefs.encodeConfig`/`decodeConfig` 的分号分隔字符串协议，并通过 `Settings.Global` 作为主通道、`XSharedPreferences` 作为回退。
- 所有需要 root 权限的操作（su 执行、Settings.Global 读写、system_server 重启）统一走 `Shell.java` 的静态方法，调用方不得直接 `ProcessBuilder`。
- 耗时或可能阻塞的 shell 调用一律提交到 `MainActivity` 内部的单线程 `ExecutorService`，结果通过 `mainHandler.post(...)` 切回主线程更新 UI。
- 对系统 API 的反射访问（`XposedHelpers.findClass`、`getStaticObjectField`、`getObjectField`）全部包裹 try/catch 并以 `XposedBridge.log` 记录失败原因，保证 Hook 异常不会崩溃宿主。
- 蓝牙设备类型等低版本未暴露的常量以字面量 switch 形式出现（如 `case 7/8/23/26/27/30`），并在注释中标注对应 `AudioDeviceInfo.TYPE_*` 常量名以保持可读性。
